*PhotoCraft*


PhotoCraft is a simple desktop photo editor built using Python and Tkinter. It allows users to edit images with basic image processing features.


*Features*


Upload Image
Increase Brightness
Adjust Contrast
Convert to Grayscale
Rotate Image
Flip Image
Blur Effect
Save Edited Image
Technologies Used
Python
Tkinter
Pillow


*Installation*


Install Pillow:

pip install pillow


*Run the Project*


python photo_editordesktop.py
